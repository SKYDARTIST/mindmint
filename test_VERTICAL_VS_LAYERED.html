Vertical vs Layered Layout Visual Test

This test verifies that Vertical layout creates a single linear chain while Layered creates multi-level hierarchy.

Vertical Layout (Single Linear Chain)

Structure: Single vertical chain, priority stack/timeline style
Pattern: Exactly one node per level, stacked top-to-bottom
NO branching, NO grandchildren, NO sibling connections 
Pattern: A --> B --> C --> D --> E
Single linear progression like a priority list or timeline
graph TD A[Main Topic] B[Priority 1] C[Priority 2] D[Priority 3] E[Priority 4] F[Priority 5] A --> B B --> C C --> D D --> E E --> F

Layered Layout (Multi-Level Hierarchy)

Structure: Multi-level hierarchy with branching
Pattern: 3 levels minimum: Root -> Level1 -> Level2
Each Level-1 node MUST have Level-2 children 
Pattern: Root --> L1A --> L2A1
                --> L2A2
       --> L1B --> L2B1
       --> L1C --> L2C1
                --> L2C2
Multi-level hierarchy with clear parent-child relationships
graph TD Root["Main Topic"] L1A["Category A"] L1B["Category B"] L1C["Category C"] L2A1["Detail A.1"] L2A2["Detail A.2"] L2B1["Detail B.1"] L2C1["Detail C.1"] L2C2["Detail C.2"] Root --> L1A Root --> L1B Root --> L1C L1A --> L2A1 L1A --> L2A2 L1B --> L2B1 L1C --> L2C1 L1C --> L2C2

Visual Comparison

Key Differences:
  • Vertical: Single path, linear progression, priority/timeline feel
  • Layered: Multiple branches, hierarchical structure, category organization
  • Immediate Recognition: Users can instantly tell which layout is which without reading labels
