🧮 De-duplication Algorithm

Jaccard Similarity: Measures token overlap between text strings, ignoring stop words

Example 1: High Overlap (REMOVED)

Text A: "Machine learning algorithms process large datasets to identify patterns and make predictions"
Text B: "Machine learning algorithms use statistical techniques to identify patterns in data and make predictions"
Tokens A: machine, learning, algorithms, process, large, datasets, identify, patterns, predictions
Tokens B: machine, learning, algorithms, statistical, techniques, identify, patterns, data, predictions
Overlap: 6/8 tokens = 0.75 similarity
Action: ❌ REMOVED (exceeds 0.6 threshold)

Example 2: Low Overlap (KEPT)

Text A: "Data preprocessing involves cleaning and organizing raw data"
Text B: "Neural networks are computational models inspired by biological systems"
Tokens A: data, preprocessing, involves, cleaning, organizing, raw
Tokens B: neural, networks, computational, models, inspired, biological, systems
Overlap: 0/11 tokens = 0.0 similarity
Action: ✅ KEPT (below 0.6 threshold)
