Mindmap Layout Enforcement Test

This test verifies that Layered layout produces multi-level depth while Classic remains flat.

Classic Layout (Should be FLAT)

Classic: Hub-and-spoke pattern
- 1 root node
- Direct connections to branches only
- NO second-level children
graph TD A[Main Topic] B[Branch 1] C[Branch 2] D[Branch 3] E[Branch 4] F[Branch 5] A --> B A --> C A --> D A --> E A --> F

Layered Layout (Should have MULTI-LEVEL DEPTH)

Layered: Multi-level hierarchy
- 1 root node
- At least 3 level-1 nodes
- Each level-1 node MUST have level-2 children
- Visible depth structure
graph TD Root["Main Topic"] L1A["Category A"] L1B["Category B"] L1C["Category C"] L2A1["Detail A.1"] L2A2["Sub-point A.2"] L2B1["Detail B.1"] L2C1["Detail C.1"] L2C2["Detail C.2"] Root --> L1A Root --> L1B Root --> L1C L1A --> L2A1 L1A --> L2A2 L1B --> L2B1 L1C --> L2C1 L1C --> L2C2

Cluster Layout (Should have MULTI-LEVEL DEPTH)

Cluster: Multi-level hierarchy
- Same structure as Layered
- Enforced 3-level minimum depth
