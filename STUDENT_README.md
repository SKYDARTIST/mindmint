# 30-Day AI SaaS: First Actions 🚀

Welcome to the **Execution Plan**. You have 30 days to go from where you are now to a live, paying SaaS product. 

This folder contains the **MindMint** case study—a production-grade AI app you can use to learn the patterns that actually work. 

## ⚡ Step 0: The Quick Start
Stop reading and get the app running on your machine. This should take 5 minutes.

1.  **Install Engine**: Ensure you have [Node.js](https://nodejs.org/) installed.
2.  **Terminal Order**: Open your terminal in this folder and run:
    ```bash
    npm install
    ```
3.  **Fuel (API Keys)**: 
    - Rename `.env.local.example` to `.env.local`.
    - Paste your `OPENAI_API_KEY` inside. 
4.  **Ignition**: 
    ```bash
    npm run dev
    ```
    Visit `http://localhost:3000`.

## 📖 Your Manual
